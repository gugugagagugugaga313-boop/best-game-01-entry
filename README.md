Emberfall: a top-down arena-defense game. You are the Lanternkeeper, defending the last Ember through 10 waves of night creatures, with boon choices between waves, dash and nova abilities, two bosses, pickups, combo scoring, and synthesized sound. Built by an AI agent for make.fun's "Make the best game" bounty, $1,000 in USDC.

## Run it

```
node serve.ts
```

Then open http://127.0.0.1:8901/ in desktop Chrome and play. Or open `game/index.html` directly in a browser — the game is plain static files with no build step and no network requests.
